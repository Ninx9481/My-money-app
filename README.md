# Money Tracker — แอพรายรับรายจ่าย (PWA + Google Sheet)

เว็บแอพบันทึกรายรับรายจ่าย (หน้าจอแอพเป็นภาษาอังกฤษ) ติดตั้งลงหน้าจอ iPhone ได้ (Add to Home Screen) เก็บข้อมูลใน Google Sheet ของคุณเอง

**ไฟล์ในชุดนี้**

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | โค้ดฝั่ง Google Apps Script (วางใน Google Sheet) |
| `index.html`, `style.css`, `app.js` | ตัวแอพ |
| `sw.js`, `manifest.webmanifest` | ทำให้ติดตั้งและใช้ออฟไลน์ได้ |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | ไอคอนแอพ |

ตั้งค่าครั้งเดียว 3 ขั้นตอน ใช้เวลาประมาณ 10 นาที

---

## ขั้นที่ 1 — สร้างฐานข้อมูลใน Google Sheet

1. เข้า [sheets.new](https://sheets.new) สร้าง Google Sheet ใหม่ ตั้งชื่ออะไรก็ได้ เช่น "รายรับรายจ่าย"
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในหน้าต่างทิ้ง แล้ววางโค้ดจากไฟล์ `Code.gs` ทั้งหมด
4. แก้บรรทัดนี้เป็นรหัสลับของคุณเอง (ตั้งอะไรก็ได้ ยาวหน่อยดี เช่น `mY-Money-2026-xyz`)
   ```js
   const SECRET = 'เปลี่ยนเป็นรหัสของคุณเอง';
   ```
5. กด **Deploy (การทำให้ใช้งานได้) → New deployment (การทำให้ใช้งานได้รายการใหม่)**
   - กดรูปเฟือง เลือกประเภท **Web app**
   - **Execute as (เรียกใช้ในฐานะ):** Me (ตัวคุณเอง)
   - **Who has access (ผู้มีสิทธิ์เข้าถึง):** **Anyone (ทุกคน)**
   - กด Deploy → กดอนุญาตสิทธิ์ (ถ้าขึ้น "Google hasn't verified this app" ให้กด Advanced → Go to ... (unsafe) เพราะเป็นสคริปต์ของคุณเอง)
6. คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec` เก็บไว้

> ชีต `Transactions` และ `Settings` จะถูกสร้างให้เองตอนใช้งานครั้งแรก

⚠️ **ถ้าแก้ `Code.gs` ในภายหลัง** ต้อง Deploy → Manage deployments → ✏️ Edit → Version: **New version** → Deploy ไม่งั้นของเดิมยังทำงานอยู่

---

## ขั้นที่ 2 — เอาแอพขึ้น GitHub Pages (ฟรี)

1. สมัคร/เข้าสู่ระบบ [github.com](https://github.com) → **New repository** ตั้งชื่อ เช่น `money` (Public)
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดยกเว้น `Code.gs` และ `README.md` ขึ้นไป
   (`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.webmanifest` และไอคอน 3 ไฟล์ .png) → Commit
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ประมาณ `https://ชื่อคุณ.github.io/money/`

> URL ของ Apps Script และรหัสลับ **ไม่ได้อยู่ในโค้ด** คุณจะกรอกในแอพบนมือถือเอง จึงไม่หลุดไปกับ repo สาธารณะ

---

## ขั้นที่ 3 — ติดตั้งบน iPhone

1. เปิดลิงก์จากขั้นที่ 2 ใน **Safari** (ต้อง Safari เท่านั้น)
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → เลื่อนลง → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** → เพิ่ม
3. เปิดแอพจากไอคอนบนหน้าจอโฮม แล้วกดรูปเฟือง ⚙️ มุมขวาบน
   - วาง **Web app URL** และ **Secret key** → กด **Test connection** ต้องขึ้น "Connected ✓"
   - แก้ชื่อบัญชีของคุณในช่อง **Accounts** (บรรทัดละ 1 บัญชี) เช่น
     ```
     🏦 KBank
     🏦 SCB
     💳 Credit card
     ```
   - ปรับหมวดหมู่ตามต้องการ (ช่อง Expense / Income categories, Travel types) แล้วกด **Save settings**
   - ปุ่ม **Reset lists to defaults** ใช้คืนค่าหมวดหมู่เริ่มต้น

เสร็จแล้ว! ถ้าจะใช้บนเครื่องอื่น ทำขั้นที่ 3 ซ้ำ ข้อมูลและการตั้งค่าบัญชี/หมวดจะซิงค์ผ่าน Google Sheet เหมือนกัน

## วิธีใช้

**หน้าบันทึก**
- เลือก **Expense / Income / 🚌 Travel** ด้านบน (ปุ่ม Travel แยกออกมา สีฟ้า มีประเภท BTS/MRT, Taxi, Motorcycle taxi, Fuel ฯลฯ)
- ใส่จำนวนเงิน → เลือก **Account** (ค่าเริ่มต้น) หรือ **Cash** → ถ้ามีหลายบัญชีให้เลือกบัญชี → เลือกหมวด (ไม่เลือกก็ได้) → **Save**
- เปลี่ยนวันที่ได้ที่ช่องวันที่ (สำหรับจดย้อนหลัง) แตะ ✕ ท้ายรายการเพื่อลบ

**หน้าสรุป**
- สลับ **Day / Week / Year** กด ‹ › เพื่อเลื่อนช่วงเวลา กดที่ชื่อช่วงเวลาเพื่อกลับมาปัจจุบัน
- เห็นรายรับ รายจ่าย คงเหลือ, กราฟ, แยกตามบัญชี/เงินสด, แยกตามหมวด, สรุปค่าเดินทาง และรายการทั้งหมด

**อื่น ๆ**
- ธีม Auto/Light/Dark และวันเริ่มต้นสัปดาห์ (Monday/Sunday) ตั้งได้ใน ⚙️
- แถบนาฬิกา/แบตเตอรี่ด้านบนของ iPhone จะเปลี่ยนตามโหมดของ **iPhone** (ตั้งค่า → จอภาพและความสว่าง) ไม่ใช่ตามปุ่มธีมในแอพ ซึ่งเป็นข้อจำกัดของ iOS แนะนำให้ใช้ธีม **Auto** จะสลับพร้อมกันทั้งหมด
- ถ้าเน็ตหลุด รายการจะเก็บในเครื่องก่อน (ขึ้น "N รอซิงค์") แล้วส่งขึ้น Sheet เองเมื่อออนไลน์ แตะป้ายสถานะมุมบน (Synced / pending) เพื่อซิงค์ทันที
- ข้อมูลทั้งหมดดู/แก้/ทำ Pivot เองได้ในชีต `Transactions`

## ความปลอดภัย

- ใครรู้ทั้ง **Web app URL และรหัสลับ** จึงจะอ่าน/เขียนข้อมูลคุณได้ อย่าแชร์สองอย่างนี้
- อย่าเอา URL/รหัสลับไปใส่ในโค้ดแล้วอัพขึ้น GitHub
- ถ้ารหัสหลุด: แก้ `SECRET` ใน `Code.gs` → Deploy เป็น New version → กรอกรหัสใหม่ในแอพ

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ทดสอบแล้วขึ้น "Can't connect" | ตอน Deploy ต้องตั้ง Who has access = **Anyone** และใช้ URL ที่ลงท้าย `/exec` (ไม่ใช่ `/dev`) |
| ขึ้น "Wrong key" | รหัสในแอพต้องตรงกับ `SECRET` ใน Code.gs เป๊ะ (แก้แล้วต้อง Deploy เวอร์ชันใหม่) |
| อัพโหลดแอพเวอร์ชันใหม่แล้วบน iPhone ยังเป็นของเก่า | เปลี่ยนเลข `VERSION` ใน `sw.js` (เช่น `v3`) แล้วอัพโหลดใหม่ จากนั้นปิดแอพให้สนิทแล้วเปิดใหม่ 2 รอบ |
| ไอคอนแอพไม่เปลี่ยนหลังอัพเดต | iOS จำไอคอนตอนติดตั้ง ให้ลบไอคอนเดิมบนหน้าจอโฮม แล้วเปิดลิงก์ใน Safari → Add to Home Screen ใหม่ (ต้องกรอก URL/Secret key ในแอพอีกครั้ง ข้อมูลรายการยังอยู่ใน Sheet) |
| ไม่มีปุ่ม Add to Home Screen | ต้องเปิดด้วย Safari (ไม่ใช่ Chrome/แอพในไลน์) |

## อัปเดตล่าสุด

- ตัวเลือกหมวด/บัญชี/ประเภทเดินทางแสดงเฉพาะชื่อ (ไม่มีอีโมจิ) ส่วนอีโมจิยังเก็บในรายการบน Google Sheet และแสดงเฉพาะในรายการ Recent entries / Entries
- หน้า Summary เป็นกราฟ (กราฟแท่งรายวัน/สัปดาห์/ปี และแถบสัดส่วนตามหมวด วิธีจ่ายเงิน การเดินทาง) แตะที่แท่งหรือส่วนของกราฟเพื่อดูรายละเอียด
- Entries อยู่ล่างสุด กดลูกศรเพื่อเปิด/ปิด (จำสถานะไว้)
- ธีมสว่างลดความเหลืองลง และช่องกรอกจำนวนเงินอยู่กึ่งกลางพอดี
- ดีไซน์แบบกระจก (Liquid Glass) บนปุ่มสลับ แท็บบาร์ และปุ่มบันทึก

วิธีอัปเดต: อัปโหลดไฟล์ทับใน GitHub แล้วปิด-เปิดแอพ 1–2 ครั้ง (ไม่ต้องลงแอพใหม่)

## อัปเดต v7

- ปุ่ม Account/Cash เล็กลง และชิปบัญชี/หมวดหมู่เล็กลง
- แยก Recent เป็นแท็บของตัวเอง (กด Show more เพื่อดูย้อนหลัง)
- แท็บใหม่ Balance: ยอดคงเหลือรวม + แยกตามบัญชีและเงินสด (ยอด = ยอดตั้งต้น + รายรับทั้งหมด − รายจ่ายทั้งหมด) กด "Set starting balance" เพื่อใส่ยอดที่มีอยู่ก่อนเริ่มใช้แอพ ยอดตั้งต้นเก็บใน Settings บน Google Sheet (ไม่ต้องแก้ Code.gs)
- ล็อกการซูม (pinch / double-tap)
- ตั้งค่า > Customize lists เป็นชิปกด × เพื่อลบ และ + Add new เพื่อเพิ่ม (กด Save settings เพื่อยืนยัน)

## อัปเดต v9 — โอนเงินข้ามบัญชี

- โหมดใหม่ "Transfer" ในหน้า Add: เลือก From / To (บัญชีใดก็ได้หรือ Cash) ใส่จำนวน แล้วบันทึก เช่น ถอนเงินสดจากบัญชี หรือโอนระหว่างบัญชี
- การโอนไม่นับเป็นรายรับ/รายจ่าย (ไม่เข้ากราฟและยอดสรุป) แต่ปรับยอดใน Balance: บัญชีต้นทางลด บัญชีปลายทางเพิ่ม
- แสดงในรายการเป็น "Transfer · KBank → Cash"
- **ต้องอัปเดต Code.gs**: วางโค้ดใหม่ทับใน Apps Script แล้ว Deploy > Manage deployments > แก้ไข (ดินสอ) > Version: New version > Deploy (URL เดิมใช้ต่อได้) ถ้าไม่อัปเดต รายการโอนจะถูกบันทึกเป็นรายจ่าย
